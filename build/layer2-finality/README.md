# acfa-finality

Round certificates, the deadline cut, and fail-visible halting: a synchrony violation produces transferable evidence instead of a silent fork.

Part of [ACFA](https://github.com/mgillr/acfa-rs). See the top-level README for the problem
this solves, benchmarks, and limitations.

cargo test
