# acfa-receipt

Signed contributions, self-authenticating equivocation proofs, a Merkle commitment trace, and a re-executable aggregate any third party can recheck offline.

Part of [ACFA](https://github.com/mgillr/acfa-rs). See the top-level README for the problem
this solves, benchmarks, and limitations.

cargo test
