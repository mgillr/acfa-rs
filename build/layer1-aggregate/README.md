# acfa-aggregate

Deterministic robust aggregation over fixed-point vectors: bit-identical output regardless of input order, accumulation order, or target architecture.

Part of [ACFA](https://github.com/mgillr/acfa-rs). See the top-level README for the problem
this solves, benchmarks, and limitations.

```sh
cargo test
```
